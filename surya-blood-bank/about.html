Home / About Us

Built by students, run for the community.

Surya Blood Bank started as a final-year academic project — and grew into a working answer to a real problem: blood requests in Kurnool were scattered across phone calls, WhatsApp groups and word of mouth.

Our mission

One searchable, trustworthy network — instead of ten scattered ones.

Every donation camp, every donor list and every hospital's stock register used to live in a different spreadsheet or notebook. Surya Blood Bank brings them into a single system: donors register once, hospitals post live stock, and patients search by blood group and location in seconds.

The platform is designed around three principles: verified donors over anonymous appeals, live inventory over guesswork, and a network that keeps working after the college project deadline passes.

Our story

From a class assignment to a working network

Semester 5 · Problem study

Interviewed local blood banks and college NSS volunteers about how donor coordination actually happens — and where it breaks down during emergencies.

Semester 5 · First prototype

Built a donor registration form and a static inventory table to test whether a simple, fast interface would actually get used at camps.

Semester 6 · Pilot donation camp

Partnered with a college NSS unit to run a pilot donation camp, registering donors directly through the platform for the first time.

Semester 6 · Current version

Added live blood-group lookup, a request workflow for patients, and a public inventory dashboard — the version you're using now.

What we stand for

The values behind every design decision

Verified, not anonymous

Every donor profile is tied to a real registration — no anonymous appeals that are impossible to follow up on.

Live over stale

Inventory numbers reflect actual stock, updated regularly, rather than a static list nobody maintains.

Built for donors, too

We only alert donors when their exact group is needed, so nobody is spammed into opting out.
